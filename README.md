# Formal Languages & Computability Coursework

Computer Science coursework exploring formal languages, mathematical logic, automata and computability through theoretical problem solving and formal proofs.

## Topics Covered

- Predicate Logic and Semantic Entailment
- Regular and Context-Free Languages
- Finite and Pushdown Automata
- Turing Machines
- Decidability and Undecidability
- Closure Properties

## Skills Demonstrated

- Formal proof construction
- Automata design
- Language analysis
- Logical and computational reasoning
